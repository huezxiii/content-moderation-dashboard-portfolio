# Project Overview
A content moderation analytics dashboard and intelligence platform inspired by enterprise speech analytics architecture. Tracks moderation queues, policy violations, reviewer accuracy, decision latency, and content safety metrics.

## Technologies Used
* **Languages:** JavaScript (ES2022), HTML5, CSS3, Python
* **Frameworks/Libraries:** Chart.js, PapaParse
* **Databases/Tools:** Git

## Key Details
* **Core Functionality:** Analytics dashboard for trust and safety operations, violation categorization, reviewer performance, and queue health.
* **Notable Architecture:** Client-side offline-first architecture with modular component structure and automated mock data generation.
