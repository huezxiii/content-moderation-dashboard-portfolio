# Project Overview
An enterprise-grade, offline-first Content Moderation and Trust & Safety analytics platform ("ApexTrust Operations"). Modeled after real-world BPO operations and the business analysis guide, it delivers end-to-end operational visibility across moderation queues, HITL automation funnels, SLA attainment, QA accuracy error distributions, and interactive workforce capacity planning.

## Technologies Used
* **Languages:** JavaScript (ES2022), Python 3.10+, HTML5, CSS3, DAX
* **Frameworks/Libraries:** Chart.js, PapaParse, JSZip
* **Databases/Tools:** Microsoft Power BI Desktop (.pbip, TMDL), Git

## Key Details
* **Core Functionality:** 4-tab operational command center featuring Executive Operations Hub, Queue & Policy Command, Quality & Appeals Assurance with audited incident drilldown, and an interactive Workforce Capacity & Erlang-C Planner implementing staffing formulas from the operations guide.
* **Notable Architecture:** Zero-CDN offline-first web architecture with Telus-inspired enterprise design tokens (`brand.css`), duration-weighted mathematical calculation engine (`stats.js`), real-time queue queuing model (`capacity.js`), programmatic client-side Power BI project generator (`powerbi.js`), WCAG 2.1 AA accessible ARIA landmarks, and 4 automated test suites (`check-*.js`).
